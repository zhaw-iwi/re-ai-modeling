# Übung 8.2 – Voltiva Ladestation

Erstellen Sie mit GitHub Copilot und PlantUML ein UML State Diagramm für die Ladestation der Voltiva AG.

## Vorgehen

1. Kopieren Sie die Requirements aus dem Übungsdokument in [requirements/voltiva.md](requirements/voltiva.md).
2. Verwenden Sie GitHub Copilot im Agent Mode und lassen Sie anhand der Requirements das State Diagramm in [voltiva-state.puml](voltiva-state.puml) erstellen.
3. Öffnen Sie mit `PlantUML: Preview Current Diagram` die grafische Vorschau.
4. Prüfen Sie das erzeugte Diagramm vollständig gegen die Requirements und die korrekte UML-Notation.
5. Korrigieren Sie erkannte Fehler mit Copilot oder direkt im PlantUML-Code.

**Wichtig:** Die Requirements sind die fachliche Wahrheit. Das von Copilot erzeugte Modell darf nicht ungeprüft übernommen werden.

Der Fokus liegt auf **Requirements verstehen → AI modellieren lassen → Ergebnis verifizieren und korrigieren**, nicht auf dem Erlernen der PlantUML-Syntax.
