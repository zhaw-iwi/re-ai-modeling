# re-ai-modeling

Lernumgebung für AI-gestützte Modellierung im Modul Requirements Engineering. GitHub Copilot im Agent Mode erstellt und verändert Modelle anhand von Requirements; die Studierenden verantworten deren fachliche und syntaktische Validierung gemäss den [.github/copilot-instructions.md](.github/copilot-instructions.md).

## Voraussetzung

Persönliches GitHub-Konto mit aktiviertem **GitHub Copilot Student**. Falls noch nicht vorhanden: zuerst den Studierendenstatus bei [GitHub Education verifizieren](https://github.com/settings/education/benefits) und anschliessend Copilot Student aktivieren.

## Übungen

- [Übung 5.2 - Change Requests](exercise-05-change-requests/README.md) - ER-Modellierung in Chen-Notation mit Draw.io
- [Übung 7.2 - Vertragserstellung Krankenkasse](exercise-07-virusana/README.md) - UML Activity Diagramm mit PlantUML

## Start in GitHub Codespaces

1. Repository über **Use this template** erstellen und **Code -> Codespaces -> Create codespace** wählen.
2. Warten, bis der Codespace eingerichtet ist.
3. `README.md` der gewünschten Übung öffnen und der Anleitung folgen.
4. Copilot-Chat öffnen und **Agent Mode** wählen.

Die Übungen verwenden unterschiedliche Modellierungswerkzeuge. **Draw.io** wird über einen MCP-Server direkt durch Copilot bearbeitet; **PlantUML** ermöglicht textbasierte UML-Modellierung mit grafischer Vorschau. Die notwendige Konfiguration ist im Codespace bereits eingerichtet.
